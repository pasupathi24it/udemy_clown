# 🎓 Udemy Clone Website (HTML & CSS)

This is a **Udemy Clone** website created using **HTML5 and CSS3**.  
The project focuses on building a clean, responsive, and modern user interface similar to the Udemy learning platform.

---

## 🚀 Features

- Responsive homepage layout  
- Course cards design  
- Navigation bar with search option  
- Category sections  
- Footer with useful links  
- Clean and beginner-friendly UI  

---

## 🛠️ Technologies Used

- **HTM**
